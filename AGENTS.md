# Project Guidelines & Workflow Rules

## Auto-Push to GitHub
- **Rule**: After completing any code changes, fixes, or feature updates requested by the user, ALWAYS automatically commit and push the latest code to the remote repository on branch `main`:
  ```bash
  git add .
  git commit -m "<concise descriptive message>"
  git push origin main
  ```
- **Remote Repository**: `https://github.com/SiddhantGpt19/GeM-Rakshak.git`
